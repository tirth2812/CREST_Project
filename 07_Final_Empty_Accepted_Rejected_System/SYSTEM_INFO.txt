PALLET TRACKING
---------------

The pallet tracker operates in 2D camera image coordinates.

Each pallet has:

- software track ID
- bounding box
- center_x
- center_y
- approximate motion information
- current classification state

Pallet center:

center_x = (x1 + x2) / 2
center_y = (y1 + y2) / 2

Current camera resolution:

1920 x 1080

Coordinate system:

(0,0) = top-left corner

X increases toward the right.
Y increases toward the bottom.

The current pallet coordinates are image pixels, not physical millimeters.


FINAL LIVE BEHAVIOR
-------------------

The system supports:

- continuous pallet tracking
- EMPTY detection
- new-object detection while conveyor is running
- fast ACCEPTED / REJECTED classification
- temporary occlusion handling
- holding the previous reliable result through hand/wire obstruction
- real object-removal detection
- updating ACCEPTED to REJECTED when the object changes
- updating REJECTED to ACCEPTED when the object changes


FINAL X / NO_X REPRESENTATION
-----------------------------

Medium-focus pallet crop:

Horizontal:
15% to 85% of pallet width

Vertical:
0% to 67% of pallet height

The crop is resized with aspect-ratio-preserving padding to 640 x 640.
